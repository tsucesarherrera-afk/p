Instrucciones

  • Backup: Exporta todas las tablas a un archivo JSON encriptado con AES-256.
  • Restaurar: Selecciona un archivo de backup previamente generado para restaurar los datos.
  • Sincronizar: Sube los datos locales a Supabase o descarga los de la nube.
  • Seguridad: La contraseña de encriptación debe ser la misma para backup y restore.
